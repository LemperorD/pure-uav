# `*_noise_density` 到底是什么量 —— 约定考证

日期：2026-10-16
为什么写这份：工作区里在用的陀螺噪声密度 **1.57e-3 rad/s/√Hz** 是用错误约定算出来的，
比正确值大 √fs ≈ 45 倍。这份文档把约定钉死，避免以后再翻车。

---

## 一、结论

```
离散噪声 std  σ_d = noise_density / √dt = noise_density · √fs
所以          noise_density = σ_d / √fs = AD(1 s)
```

`AD(1 s)` = 平均时间 τ = 1 秒处的 Allan 偏差。

白噪声区的等价写法（与 fs 无关，物理量本该如此）：

```
AD(τ) = noise_density / √τ        ⟹   noise_density = AD(τ)·√τ
```

随机游走区：

```
AD(τ) = random_walk · √(τ/3)      ⟹   random_walk  = AD(τ)·√(3/τ)
```

## 二、三条独立证据

### 证据 1：Kalibr 源码（本地 `~/下载/kalibr-master`）

`aslam_offline_calibration/kalibr/python/kalibr_common/ConfigReader.py:490-492`

```python
def getGyroStatistics(self):
    self.checkGyroStatistics(self.data["gyroscope_noise_density"], self.data["gyroscope_random_walk"])
    gyroUncertaintyDiscrete = self.data["gyroscope_noise_density"] / math.sqrt(1.0/self.getUpdateRate())
    return gyroUncertaintyDiscrete, self.data["gyroscope_random_walk"], self.data["gyroscope_noise_density"]
```

`math.sqrt(1.0/update_rate)` = √dt = 1/√fs。
所以 `gyroUncertaintyDiscrete = noise_density · √fs`。**教科书式的直证。**

### 证据 2：OpenVINS 源码（本地 `~/vio_ws/src/open_vins`）

`ov_init/src/sim/SimulatorInit.cpp:326-331`

```cpp
wm(0) = omega_inI(0) + true_bias_gyro(0) + params.sigma_w / std::sqrt(dt) * w(gen_meas_imu);
wm(1) = omega_inI(1) + true_bias_gyro(1) + params.sigma_w / std::sqrt(dt) * w(gen_meas_imu);
wm(2) = omega_inI(2) + true_bias_gyro(2) + params.sigma_w / std::sqrt(dt) * w(gen_meas_imu);
am(0) = accel_inI(0) + true_bias_accel(0) + params.sigma_a / std::sqrt(dt) * w(gen_meas_imu);
```

这行是 OpenVINS 自己的**仿真器造数据**的代码 —— 它按 `sigma_w/√dt` 生成离散噪声。
同一个约定。

`ov_msckf/src/utils/NoiseManager.h:36-58` 的默认值就是 EuRoC 的：
```
sigma_w  = 1.6968e-04   // rad/s/sqrt(hz)
sigma_wb = 1.9393e-05
sigma_a  = 2.0000e-03
sigma_ab = 3.0000e-03
```

### 证据 3：硬件反推（拿 ADIS16448 对数据手册）

EuRoC 的 IMU 是 ADIS16448，公布标定值 `gyroscope_noise_density = 1.6968e-04 rad/s/√Hz`，
`update_rate = 200 Hz`。

| | 计算 | 结果 |
|---|---|---|
| 由约定推出的离散 std | 1.6968e-4 × √200 | **0.1375 °/s** |
| ADIS16448 手册噪声密度 0.0085 °/s/√Hz | 0.0085 × √200 | **0.12 °/s** |

两者吻合（差 15%）。**说明把它当"连续密度"解释在物理上是对的。**
反过来若把它当"离散 std"，则相当于手册值的 1/14 —— 一颗 ADIS16448 不可能那么安静。

## 三、数字怎么从 Allan 曲线读出来

### 白噪声密度

Allan 偏差（重叠式，簇长 m = τ·fs，输入是采样率 fs 的离散序列）：

```
AD(τ) = σ_d / √(τ·fs)
```

代入 σ_d = noise_density·√fs：

```
AD(τ) = noise_density / √τ          ← 与 fs 无关
```

在双对数图上是斜率 -1/2 的直线。**在两三个十倍程内 `AD(τ)·√τ` 保持平坦的那一段**，
取中位数就是 noise_density。

⚠️ **必须在最短 τ 端找这一段。** 漂移区（长 τ 端）的斜率有时碰巧也是 -1/2，
拟合 R² 能到 0.99，但报出来会大两个量级。实测 log_8 就踩过：
τ=2~213 s 的漂移区拟合出 5.2e-3，而最短 τ 处直接读数是 2.8e-5。

### 随机游走

```
AD(τ) = random_walk · √(τ/3)
```

只在【曲线真的超出白噪声预言】的 τ 段里读，并且要用两项模型

```
AD²(τ) = σ²/τ + K²·τ/3
```

把 σ 固定住再解 K —— 否则交叉点附近"白噪声还在贡献"会让 K 偏大。

### 时长要求

| 要测的量 | 需要多长 |
|---|---|
| 噪声密度 | 10 分钟就够（只要覆盖 -1/2 区） |
| **随机游走** | **4~8 小时**（要 τ 到百秒量级才看得到 +1/2 区） |

这就是为什么之前的随机游走一直用"典型值" —— 数据只有 19 分钟。

## 四、顺手记一个坑：别直接拿 imu_utils 的 `gyr_n` 填 OpenVINS

`imu_utils`（gaowenliang，包含在你给的 `Calibration-Is-All-You-Need` 里）
`src/gyr_lib/fitallan_gyr.cpp`：

```cpp
double FitAllanGyr::getWhiteNoise() const {
    return sqrt(freq) * sqrt(calcSigma2(Q,N,B,K,R,1)) / (57.3*3600);
}
```

数据内部单位是 deg/hour，`/(57.3*3600)` 转成 rad/s，所以：

```
imu_utils 的 gyr_n = √fs · AD_fit(1) = σ_d     ← 离散 std，不是密度
```

**跟 Kalibr/OpenVINS 要的差 √fs 倍。**

旁证（**只是旁证，不是定论**）：

| | imu_utils 输出 | 手册值 | 比值 |
|---|---|---|---|
| BMI160 | `gyr_n = 1.2138e-3` | 0.007 °/s/√Hz = 1.22e-4 rad/s/√Hz | **9.93 ≈ √100** |

`√fs = 9.93 ⟹ fs ≈ 100 Hz`，正是 BMI160 常用的记录速率 —— 吻合得很好。

⚠️ 但 `imu_utils/data/16448_imu_param.yaml` 里 `gyr_n = 1.858e-4`，
与 EuRoC 公布的 1.6968e-4 只差 9.5% —— **这个例子对不上**（按离散 std 解释该差 14 倍）。
所以这条我只能当提醒，不能当定论。

**本工具（`analyze_static_noise.py`）不走 imu_utils**，直接按上面第二节的公式算 `AD(1)`，
并且先用合成数据反解自检（给定已知 σ/K，能反解回来才允许碰真实数据）。

## 五、IIM-42652 手册值（已查证）

出处：**IIM-42652 datasheet DS-000440 Rev 1.1**

| 表 | 参数 | 值 | 换算 |
|---|---|---|---|
| Table 1 陀螺 | Rate Noise Spectral Density @ 10 Hz | **0.0038 º/s/√Hz**（TYP，注 1 = Tested in production） | **6.632e-05 rad/s/√Hz** |
| Table 2 加计 | Power Spectral Density @ 10 Hz | **70 µg/√Hz**（TYP，注 1） | **6.865e-04 m/s²/√Hz** |

**手册自洽性检查**（这行很重要，说明这两个数不是随手写的）：

```
陀螺 Total RMS Noise = 0.038 º/s-rms @ 带宽 100 Hz
   → 0.0038 × √100 = 0.038  ✓
加计 RMS Noise = 0.70 mg-rms @ 带宽 100 Hz
   → 70e-6 × √100 = 0.00070 g = 0.70 mg  ✓
```

**量化台阶**（Table 1，GYRO_FS_SEL=0）：

```
±2000 º/s，16.4 LSB/(º/s)  →  1 LSB = 1/16.4 = 0.06098 º/s = 1.0643e-03 rad/s
在 2 kHz 采样下，手册噪声的离散 std = 0.0038×√2000 = 0.17 º/s ≈ 2.8 LSB
量化噪声本身 = LSB/√12 = 0.29 LSB  →  约占总噪声方差的 1%
```
