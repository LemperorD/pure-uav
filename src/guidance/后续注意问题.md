## 2. 换真机必须改的参数（一行错，全盘错）

| 参数 | 仿真值 | 真机值 | 为什么 |
| --- | --- | --- | --- |
| `GuidanceParams::los_rate_source` | `FROM_RELATIVE_VELOCITY` | **`FROM_LOS_DIFFERENCE`** | 真机拿不到 `v_T`；ω 只能由 `û` 历史差分算出 |
| `GuidanceParams::freeze_criterion` | `BY_TGO` | **`BY_TGO_OR_RANGE`**（或 `BY_RANGE`） | `Vc → 0` 时 `t_go = R/Vc` 会发散，必须用 R 兜底 |
| `GuidanceParams::a_max` | 核默认 `30` | **机体的真实水平过载**（x500 约 `10 m/s²`） | 限幅值必须与机体能力一致，否则指令给不出、饱和成常态 |
| `adapter::AttitudeFrame` | `kFrd`（默认猜测） | **对方实际给的机体轴** | 见 §1 #1 |
| `GuidanceParams::N` | 核默认 `4`，节点默认 `6` | 工程取 **3~5**；静止靶 TPN 用 2~4 | 导航比；过大易振荡、过小修正不足 |

⚠ 四元数顺序统一 **`[w,x,y,z]`**，与 PX4 uORB / MAVLink 一致 —— **不要转**。

## 3. 时间与时标（三条铁律）

1. **只取差值**，且两端**必须同源**：`TimeBase::kSameSource`。跨源相减**不报错**，只会静默给出垃圾 `dt`。
2. **回绕**：MAVLink `time_boot_ms` 是 `uint32`，约 **49.7 天**回绕 ⇒ 必须用
   `ms_diff_u32` / `ms_diff_to_s` / `ms_elapsed`，**禁止** `now > deadline` 这种写法。
   PX4 uORB `timestamp` 是 `uint64` µs ⇒ **先整数相减再转 double**（避免 `2^53` 精度问题）。
3. **序列监控**：单帧跳变 > 5 s 视为可疑（`StateTimeTracker::last_jump_suspect()`），
   乱序帧计数 `out_of_order()`；制导本身只在 `dt < 1e-9` 时退化为零。

## 4. 坐标系与单位（只在边界转一次）

| 项 | 内部口径（冻结） | 外部口径 |
| --- | --- | --- |
| 惯性系 | **ENU**（x 东 / y 北 / z 上） | NED（PX4 / MAVLink） |
| 机体轴 | **光轴系**（x 右 / y 下 / z 前） | FRD（PX4）/ FLU（ROS） |
| 单位 | m / (m/s) / m/s² / rad / s | mm / cm/s / cdeg / degE7 / ms / µs |

- **入口唯一**：`adapter::to_guidance_state()`；
- **出口唯一**：`adapter::cmd_accel_to_ned()`；
- 其它任何地方再做一次换算 ⇒ 会出现"z 翻回去"这类静默 bug。

⚠ `Vec3::normalized()` 对零矢量**返回零矢量**（不是 NaN）。换库时（例如 Eigen 的
`.normalized()`）会变成 NaN，而视线退化是真实存在的分支 —— **不要把 `vec3.hpp` 换掉**。

### 4.1 ★ 无 GPS：惯性系 = 初始机体坐标系（2026-10-20 与通信组确认）

**事实**：本机飞控**没有 GPS**，local 局部系没有真北参考 ⇒ 它的航向零点就是
**EKF 初始化（上电 / 起飞）那一刻的机头方向**：

| 轴 | 实际含义 | 与"真 NED"的差别 |
| --- | --- | --- |
| x | **初始机头方向** | 差一个固定偏航角 θ₀ |
| y | 初始机头右侧 | 同上 |
| z | **下**（PX4 惯例不变） | 一致 |

⇒ `src/common/msg.hpp` 里写的 **"初始 FRD"在语义上是准确的**（不是笔误）。
我们内部照旧 `ENU = (N.y, N.x, −N.z)`，得到"初始机头对齐 + z 朝上"的**局部 ENU**。

**对制导律：零影响。** PN 族全是矢量运算，对惯性系的整体刚性旋转不敏感 ——
`a = N·(ω × v_M)`、`ω = (r × v_rel)/R²`、`Vc = −(r·v_rel)/R` 里的 `cross`/`dot`
在正交变换下不变。只要 `p / v / los / r` 在**同一个系**里即可。
⇒ `Frame::kNed` / `AttitudeFrame::kFrd` 参数不变，**算法一行不改**。

**但它把两个责任推给了外部**：

| # | 责任 | 要求 | 现状 |
| --- | --- | --- | --- |
| 1 | **位置必须由 VIO/视觉喂飞控** | EKF 没有水平位置/速度源时 `LOCAL_POSITION_NED` 一直 invalid（`xy_valid=false`），offboard 起不来。入口是 `Communicator::pushVisionPose()` | 🔴 VIO 分支**只有标定工具**，运行时 VIO 未写 |
| 2 | **目标必须用相对量给** | 视觉直接给"机体系视线 + 距离"，我们用 `q` 转到本系 ⇒ **不需要绝对坐标**，也不用知道北在哪 | 🔴 检测模块尚无代码 |

**不推荐的做法**：把装甲板的场地绝对坐标按 θ₀ 平移进来 —— 依赖"摆正起飞 + 人工标定 θ₀"，
一旦摆歪就是系统性偏差，而且 EKF 一重置就全废。

**两个必须监控的风险**：

- **EKF 重置**：飞行中若 yaw / 原点被重新初始化，坐标系会**跳变** ⇒ 任何缓存的绝对量瞬间失效。
  主循环必须监控 estimator 状态，一旦 reset 就中止或重新对齐。
- **高度漂移**：无 GPS 时高度靠气压计 / 视觉，长时间会漂。而 **Δz 是撞板的关键量之一** ⇒
  接近段应尽量用测距/视觉校正，至少把高度漂移纳入失败分析。

## 5. 算法红线（评审 / 答辩必被问）

| 红线 | 说明 |
| --- | --- |
| **ω 的分母是 R²** | `ω = (r × v_rel) / R²`，不是 R |
| **限幅是矢量等比缩放** | 禁止对 x/y/z 分量各自 clip（会改变指令方向） |
| **t_go 小 → 冻结（HOLD）** | `1/R` 会把视线噪声放大成大指令 ⇒ 冻结为上一周期指令 |
| **默认 PPN** | `a = N·(ω × v_M)`；不含距离项 ⇒ 对测距误差免疫 |
| **纯函数** | `guidance_step(state, params, memory) -> cmd`，不读全局、不碰 I/O；换真机一行不改 |

**两条实测结论**（《待决问题》里没写的，来自本轮/上轮实测）：

- **零速死区**：PPN 在 `v_M = 0` 时指令恒为零 ⇒ **必须先预加速（CRUISE）再交给制导**，
  悬停起步必脱靶（离线已验证：最近 1.07 m）。
- **静止靶用 TPN 是正当的**：`v_T = 0` ⇒ `Vc` 精确；APN 退化成 TPN（`a_T = 0`），实测两者**逐位相同**，
  不用试 APN。N=2 时 miss 4 mm、饱和 0%，比 PPN 更准更省。
- **修正预算是硬约束**：可修偏差 ≈ `½·a_max·t_go²`。高速 + 小窗口下换任何导引律都救不回来
  （实测 `t_go=0.456 s` 只够修 1.04 m，而偏差 1.91 m ⇒ 脱靶 1.43 m）。

## 6. 机载工程注意（本轮实测数据）

| 项 | 数据 | 结论 |
| --- | --- | --- |
| `guidance_step`（单 TU 内联） | ≈ **7 ns** | 算力不是瓶颈 |
| `guidance_step`（跨 TU，无 LTO） | **30 ns** | SHARED 库跨不过 DSO 边界 ⇒ LTO 也救不了 |
| 同上 + LTO（**静态链接**） | **6.7 ns** | 要吃这个收益：核心改 STATIC + `-flto` |
| `check_guidance_state` | **69 ns**（原 981 ns，已优化 14×） | 失败时才构造字符串 |
| `quick_check`（零分配） | **7 ns** | **飞行回路用这个** |
| `to_guidance_state` | ≈ 20~24 ns/帧 | 含四元数 Shepperd 重建 |

其它：
- **不要 `-ffast-math`**：会破坏 NaN / `isfinite` 语义与限幅边界判据。
- **循环内零分配**：不 `printf` / 不 `std::string` / 不 `new`；日志写预分配环形缓冲，循环外落盘。
- **时钟用单调时钟**（`steady_clock` / `CLOCK_MONOTONIC`），不要墙钟。
- 周期节拍用**绝对时间睡眠**（`TIMER_ABSTIME`），`sleep_for` 会累积漂移。

## 7. 仿真侧注意（`sim_xtdrone2/`）

- **只跑一条 launch**：`ros2 launch xtd2_launch ros2_single_vehicle_demo_launch.py`；
  不要再单开 MicroXRCEAgent，也不要 `make px4_sitl`（双套拉起 + 抢 8888 端口）。
- **起降只发 `cmd_vel_ned`**：accel 模式是纯前馈（`a_z=0` 就掉高），且会把
  `trajectory_setpoint` 的 velocity 打成 NaN（永久污染落地检测）。
- **改板 `--plate-yaw` / `--plate-pitch` 必须重启 Gazebo**：实体幂等复用只查位置、不查朝向。
- **`--target-height` 不会自动对齐板高** —— 这是刻意的测试变量，别让它"作弊"。
- 选项一律 `--opt=value`（`--plate-center -14,0,5` 会把 `-14` 当选项名）。
- QGC 用英文界面；Ctrl-C **一次** = 优雅收尾（LAND → 停桨），两次 = 强制退出。
- 构建：`build_guidance_shim.sh` 现在会从 `src/common/common_libs/include/` 额外拷 `vec3.hpp`
  （2026-10-20 目录重构后必须）。
