# 飞控与上位机通信模块——吴钦沅

## 1. 制定好通信什么

理清楚**飞控到上位机(fcu->pc)**以及**上位机到飞控(pc->fcu)**双端都要通信什么信息

- fcu->pc: imu数据,当前飞行模式，电池电量等
- pc->fcu: 定位数据，飞行模式切换信息，起飞/降落指令

要和目标检测与vio的同学取得联系，他们需要这些数据做后续的功能

## 2. 写mavlink代码

指定好通信数据之后写mavlink代码，放在``driver/communicate``中
